# Fixtures

- `chapter-clean.txt` — Part I of "A Scandal in Bohemia" (*The Adventures of Sherlock Holmes*, Arthur Conan Doyle, Project Gutenberg #1661, public domain), ~3.4k words with dialogue and proper names. Source, URL and licence are in a comment header: lines starting with `//` are comments and `domain.segmentation` skips them (`//` rather than `#`, because `# Heading` is Markdown).
- `excerpt.txt` — the title and the first three paragraphs of the same chapter (~20 sentences). Development and integration tests use this; the full chapter only runs in `make metrics`.
- `chapter-defects.json` — 20 deliberate edits (8 omission, 5 repetition, 5 substitution, 2 truncation), each located by a text `anchor` (a unique phrase from the target sentence) rather than a sentence index, so the fixture survives changes to the segmentation rules. `tests/support/plant_defects.py` applies them to produce the "actual" text used in detection tests, so detection quality is measurable without any API call.
- Detection tests feed `chapter-actual.txt` (generated by the test, git-ignored) in place of a Scribe transcript; the audio checks use synthetic WAVs generated in the test.

Never add copyrighted text or generated audio of copyrighted works.
