# Explain Python for a TypeScript developer

For the selected code or concept:

1. One-paragraph plain explanation of what it does.
2. A two-column comparison: Python on the left, the closest TypeScript equivalent on the right. Mark where the analogy breaks.
3. The 1–3 things that most often surprise TS developers here (runtime vs static typing, mutability, async semantics, import system).
4. One question the developer should be able to answer afterwards without notes.
5. Offer to append the explanation to `docs/learning-log/python-for-ts-devs.md` under a matching heading. Only append if the developer agrees.
